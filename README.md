## Description

A little personal website with blogs, projects, experiments, and other silly stuff :3

It has animated page transitions, custom artwork, and a handmade cover image inspired by old neocities/webcore sites.

---

## Testing it locally

```bash
git clone https://github.com/mannireis/website
cd website

npm install
npm run dev
```

Runs on `localhost:4321`
